# Section 4-10 — Application of trade description

4-10  Application of trade description 
 
 If a trade description is applied at a registered establishment to prescribed plants 
or plant products that have been prepared for export at the establishment, the 
trade description must include the information referred to in subsection 8-6(1) 
(other than any information referred to in that subsection that is included in a 
trade description already applied to the plants or plant products). 
Note: 
The trade description must also comply with section 8-7 and subsection 8-8(2).
