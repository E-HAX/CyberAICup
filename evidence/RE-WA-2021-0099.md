6. Hygiene and Waste Controls (Checking Point 3.1)
Hygiene and Sanitation Program (AOW-HSP-001):
• Equipment cleaning: pressing equipment (linseed press, conveyors) cleaned with food-safe degreaser between product changes.
• Silo interiors cleaned by air-sweep before new season intake.
• Personnel hygiene: access control to processing area; no food or drink in processing zone.
• Oil tanker hygiene: tanker interior inspected and swabbed before filling; HACCP tanker form completed.
• Records: Cleaning Register (AOW-CLN-01) signed after each event.
Waste Management Procedure (AOW-WMP-001):
• Scalper screenings / trash: collected in sealed bins; transported off-site to approved composting.
• Oilseed dust: cyclone dust collector; dust collected in sealed bags; removed weekly.
• Linseed meal (pressing by-product): sold to livestock feed market; removed within 48 hours of pressing.
• Chemical waste: fumigant and pesticide containers disposed per APVMA label; manifest maintained.
• Wastewater from cleaning: directed to grease trap; collected by liquid waste contractor monthly.
7. Pest Control (Checking Point 3.2)
Pest Control Program (AOW-PCP-001):
• Rodents: 16 perimeter bait stations (Bromadiolone); monthly inspection; licensed contractor annual review.
• Insects: pitfall traps in each silo; grain temperature probe weekly in storage season; phosphine fumigation when insects detected.
• Bird exclusion: all structural openings sealed; netting at loading conveyor ends.
• Records: Pest Control Log (AOW-PC-01) monthly.
8. Traceability and Integrity (Checking Point 4.1)
Traceability System (AOW-TRACE-001):
• Each silo assigned unique ID (silo number + commodity + IP/non-GM status + season).
• Receival dockets link grower → farm block → variety → quantity → silo.
• Dispatch: bill of lading links silo ID → vessel/tanker → destination.
• GM testing records linked to lot reference; retained 5 years (EU requirement).
• One-step-forward / one-step-back trace exercise performed semi-annually.
9. Product Flow Chart and Failed Goods (Checking Point 4.1)
[DEFICIENCY] No standalone product flow chart diagram attached to this HACCP plan.
Failed Goods Procedure (AOW-FGP-001):
• GM contamination above threshold: lot re-classified as non-Identity Preserved; customer notified; DAFF notified.
• Mycotoxin exceedance: silo placed on HOLD; re-test from secondary sample; if confirmed, dispose to non-food use.
• Pesticide MRL: reject export consignment; segregate; grower liability documented; option to process to domestic oil (if MRL met under FSANZ).
• All non-conformances recorded in AOW-NCR register with root cause analysis.
10. Phytosanitary Security / Contamination Risk (Checking Point 4.2)
Phytosanitary Security (AOW-PSP-001):
• Export-cleared grain stored in dedicated silos; not accessible to uncleared grain.
• Identity Preserved (non-GM) lots in dedicated, clearly labelled IP silos.
• Loading procedure: transport unit inspected before loading; last cargo record reviewed; sealed containers sealed at point of loading.
• DAFF sampling completed before loading of each export lot.

5.  AREA-SPECIFIC CLEANING PROCEDURES (SOPs)
Detailed step-by-step procedures for each area of the establishment
Receival / Intake Hopper
After each intake run: Lock out receiving conveyor. Use compressed air lance to dislodge pulse residue from hopper walls, conveyor trough, and all transition points. Vacuum accumulated screenings and fine material. Inspect underside of conveyor belt for product trapping. Record in Intake Checklist.
Cleaner / Aspirator / Colour Sorter
After each cleaning run: Remove accumulated screenings from collection trays and hoppers. Brush aspirator screens with dedicated brush to remove lodged seeds. For colour sorter: follow manufacturer's lens cleaning protocol. Vacuum sensor housings. Inspect all filters and replace if blocked. Record in Plant Operator Run Log.
Storage Silos / Bins
Designated staff are responsible for maintaining the Storage Silos / Bins in a clean and hygienic condition following each production run or daily as scheduled. Appropriate cleaning agents at specified dilutions shall be used. Completed cleaning activities are to be recorded in the site cleaning log.
Packing Line / Bagging Machine
End of each shift: Clear all pulse product from the line. Vacuum or brush conveyor belts, weigh hoppers, and bag former guides to remove pulse fines. Prepare ProClean 200 at 1:50. Wipe external surfaces of bagging machine and packing bench. Check sealing jaws and heat elements for residue. Record in Shift Log.
Palletising Area / Loading Dock
Designated staff are responsible for maintaining the Palletising Area / Loading Dock in a clean and hygienic condition following each production run or daily as scheduled. Appropriate cleaning agents at specified dilutions shall be used. Completed cleaning activities are to be recorded in the site cleaning log.
